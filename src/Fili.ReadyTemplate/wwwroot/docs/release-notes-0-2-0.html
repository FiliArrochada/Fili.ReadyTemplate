Fili.ReadyTemplate 0.2.0: Release Notes

Product Release Information

Product: Fili.ReadyTemplate, a continuation of ReadySET
Release Number: 0.2.0
Release Date: 2026/09/16
Previous Release: 0.1.0
Customer Support: Questions and problem reports go to the issue tracker.

Introduction

This release makes the site multilingual. The pages around the templates, the navigation bar, the home page and the browse page, are now rendered by a small Blazor WebAssembly application and can be read in English or Portuguese; a language switch sits at the right of the navigation bar and the choice is remembered. The templates themselves are unchanged and remain plain HTML files that work on their own.

What's New?

  • Two languages. The site's own text is available in English and Portuguese. The browser's language picks the default; the switch in the navigation bar overrides it and the choice is kept in the browser.
  • Translated content, when it exists. A template or documentation page can have a translation stored in a culture-named folder beside the original, for example templates/pt/proposal.html next to templates/proposal.html. When a visitor reads the site in that language the translation is shown; when there is none, the English original is shown with a note saying so. No template has been translated yet: this release provides the mechanism, and translations will follow as separate work.
  • Templates stay standalone. Every template is still a self-contained HTML file under templates/. Opened directly, it renders exactly as in 0.1.0 with its own navigation bar; opened through the site, that bar is replaced by the localized one.

Installation and Upgrade Notes

Installation
Nothing changes for users of the templates: download the archive or clone the repository and copy src/Fili.ReadyTemplate/wwwroot/templates into your project. The folder moved one level down in the repository so it can be published as part of the site; its contents are the same.
Manifest
This release consists of the following items:
  • HTML templates and CSS stylesheets (unchanged from 0.1.0)
  • FAQ, HOWTO-upgrade, recommended tools, and release notes
  • The Blazor WebAssembly site that presents them, with English and Portuguese strings
Minimum System Requirements
The templates need only a text editor and a web browser. The site needs a browser with WebAssembly, which every current browser has; without JavaScript the templates and docs can still be opened as files.
Version Compatibility
Documents made from any earlier release need no changes.

Known Problems and Workarounds

  • Deep links to a page that exists only as a route, such as the browse page, are answered by GitHub Pages with a 404 status before the application takes over and shows the page. Browsers do not care; search engines may.
  • Switching language reloads the page, because the runtime loads one culture's resources at startup.
