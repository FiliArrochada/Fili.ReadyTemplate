Fili.ReadyTemplate 0.1.0: Release Notes

Product Release Information

Product: Fili.ReadyTemplate, a continuation of ReadySET
Release Number: 0.1.0
Release Date: 2026/09/16
Based On: ReadySET 0.9.3 (2004/10/27) by Jason Robbins; see the 0.9.3 release notes and the ReadySET license
Customer Support: Questions and problem reports go to the issue tracker of the repository that publishes this site.

Introduction

This document contains the release notes for Fili.ReadyTemplate version 0.1.0. The following sections describe the release in detail and provide information that supplements the main documentation.

Fili.ReadyTemplate is a continuation of ReadySET, the library of software engineering document templates that Jason Robbins published at readyset.tigris.org. That project ended when Tigris.org shut down; 0.9.3 (2004) was its last release. This first release of Fili.ReadyTemplate changes nothing about what the templates say: it brings the pages up to current web standards, restyles them, and repairs the links that died with Tigris.org. The templates remain Jason Robbins' work under the ReadySET license, which also records the original project's history and contact details. Fili.ReadyTemplate is not affiliated with or endorsed by the ReadySET author.

What's New?

  • HTML5 pages. Every page lost its XML prologue and Tigris DOCTYPE and gained <!DOCTYPE html>, a language attribute, a UTF-8 charset and a viewport declaration. The inline @import blocks became <link> tags to the three stylesheets.
  • New stylesheets. readyset.css is rewritten on CSS custom properties: a readable single column, system fonts, responsive tables, and a dark colour scheme that follows the operating system. inst.css is still the customisation layer and now carries commented examples for every toggle. print.css still hides the sticky notes and the footnote on paper. Every class name from ReadySET 0.9.3 is honoured, so documents made from the original templates render correctly with the new files.
  • No more frames. The frameset, its navigation frame and the JavaScript tree were replaced by a browse page that lists the templates by activity, by suggested sequence and alphabetically, and now includes the twelve worksheets the old tree never showed. A navigation bar at the top of every page links back to it; that bar is the one addition inside each template and is meant to be deleted when a template is copied into a project.
  • Links repaired. Everything that pointed at the dead readyset.tigris.org was repointed: the words of wisdom essays to the Internet Archive, downloads to the repository, the glossary and home page to this site, the mailing list and issue tracker to the repository's issues. Eleven mistyped internal links and anchors were corrected.
  • ReadySET Pro references removed from the templates. The commercial companion to ReadySET is no longer sold: its website is a 2010 snapshot whose checkout posts to a payment processor that closed in 2016. The sentence inviting you to evaluate it was removed from the TODO box at the foot of every template. Mentions in the original author's prose on the overview page, in the FAQ and in the license file were left as written.

Installation and Upgrade Notes

Installation
Fili.ReadyTemplate is not a program, it is just a set of HTML templates, so no installation is needed.
Download the archive or clone the repository, copy the templates folder into your project website or version control system, and edit the templates to describe your project.
Manifest
This release consists of the following items:
  • HTML templates and CSS stylesheets
  • FAQ, HOWTO-upgrade, recommended tools, and release notes (this file, plus the ReadySET 0.9.0 to 0.9.3 release notes kept for history in the docs/readyset folder)
Minimum System Requirements
You can use the templates on any computer that can run a text editor and a web browser. The stylesheets use CSS custom properties, which every browser released since 2017 supports; in an older browser the pages still read correctly, only unstyled.
Version Compatibility
Documents filled in from ReadySET 0.9.3 or earlier need no changes. To pick up the new look, replace your copy of the css folder with this release's and add the three <link> tags from any 0.1.0 template to the <head> of your pages in place of the old <style> block. The upgrade HOWTO describes the version-control side of an upgrade; its CVS commands date from 2004 but the approach applies to any system.
The frameset.html, frame-nav.html and frame-select-at-left.html pages, the js folder, and css/nav.css with its folder icons were removed. Nothing in a filled-in document referenced them.

Known Problems and Workarounds

  • The sample test suite in test-suite.html refers to example test cases and use cases that the sample test-cases.html and use-cases.html do not contain, so those anchors land at the top of the page. They are illustrations of the naming pattern, not defects to fix, and were left alone.
  • sdm.html is the same placeholder it was in ReadySET 0.9.3; links into its sections land at the top of the page.
  • The words of wisdom essays exist only in the Internet Archive. If a snapshot is missing, the Archive's calendar view usually has a neighbouring one.
